# mfhtechnologies.co.za

The MFH Technologies website: plain HTML and CSS, no build step, no outside scripts, fonts or cookies.

- `index.html`: the company, what it owns (the Tiekie platform, DalaDish), licensing and the company details required by ECTA s43.
- `privacy.html`: the website's privacy notice (server logs and email only).
- `assets/`: the official MFH Technologies CI v2.0 artwork, copied unchanged from Drive
  (`Tiekie — Company/06-Brand/06-05_MFH-Technologies-CI`), and `site.css`.

Follow the CI: the gradient lives in the mark only; colour lock-up on white, white lock-up on charcoal; Inter with the
Arial and Helvetica fallback; no tagline; use ™ (never ®) until MFH TECHNOLOGIES is registered.

Preview: `python3 -m http.server 8091` in this folder, then open http://localhost:8091.
